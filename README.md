# School Dash Website

This is a static download website for School Dash.

## Files

- `index.html` - website
- `style.css` - styling
- `downloads/SchoolDash-macOS.zip` - put your Mac build ZIP here
- `downloads/SchoolDash-Windows.zip` - put your Windows build ZIP here

## Important

The two download ZIPs are intentionally not included yet because the final Mac `.app` and Windows executable need to be supplied.

Once the ZIPs are placed in `downloads/`, the buttons in `index.html` will download them.

## Publishing

This site can be hosted for free with GitHub Pages, Netlify, or another static host.
